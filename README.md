# SPHinX Assistant

Formal Semesterarbeit project workspace.

## Repository layout

- `repos/SPHinXsys`: read-only full clone of the SPHinXsys source repository.
- `repos/SPHinXsim`: read-only full clone of the SPHinXsim source repository.
- `src`, `scripts`, `tests`, `configs`, `data`: project-owned assistant materials.

The repositories beneath `repos/` must not contain assistant code or source modifications. They may be inspected, parsed, and queried through Git history and diffs.
